# Insightistic verified feature catalog

The application checkout exposes these implemented product areas for marketing
documentation:

- WooCommerce: revenue, orders, products, customers, refunds, comparisons and
  business-level analytics.
- Traffic: traffic overview and dimensions, with supported Google/GA4 data
  connections.
- SEO: Search Console overview, queries, pages, Bing data, rank/search
  intelligence and crawl-backed technical signals where connected.
- Performance: PageSpeed/Core Web Vitals workflows, site health, uptime and
  broken-link/issue monitoring where the connected site has data.
- AI: Ask Insightistic, saved insights, investigations, AI insights, anomaly
  review, action proposals requiring human approval, and outcome verification.
- Reports: client-ready reports, scheduled delivery and agency workflows.
- Agency: portfolio overview, client grouping, team roles, usage controls and
  supported white-label settings.
- Integrations: WordPress connector, WooCommerce, Google/GA4/Search Console,
  Cloudflare, billing and secure sync workflows.

Feature availability, limits and empty states depend on the connected site,
account plan, provider connection and current application catalog.
