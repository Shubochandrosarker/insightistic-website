# Updating the Insightistic AI handoff

1. Review the current public website and the application catalog endpoint.
2. Confirm the catalog version, subscription limits, credit packs and Founding
   Angel campaign state from the application source or a complete API response.
3. Update the six files in this directory together so the product profile, FAQ,
   feature catalog and pricing reference stay aligned.
4. Keep unsupported claims out: no invented testimonials, certifications,
   rankings, customer counts, deadlines, guarantees or OpenAI endorsement.
5. Treat the application checkout as authoritative for final eligibility and
   never implement a second LTD inventory counter in an AI assistant.

This bundle documents website-owned product information for external handoff. It
does not change any ChatGPT listing, app configuration or external knowledge
source automatically.
