Date: 2026-11-25 · Repo `insightistic-website` · Branch `feat/v3-rebrand` @ `1f456c9`

## 1. CTA slug audit — the result

The theme contains **exactly one AppSumo CTA**, and it is the top announcement bar
(`template-parts/global/promo-bar.php`). It calls `insightistic_promo_url()` with **no argument**, which
resolves to the website token `-w` — correct by design, because that is the surface every visitor sees.

There are no other AppSumo links in the theme: no second `insightistic_promo_url()` call site, no
hard-coded `appsumo.com` anchor anywhere in a template. So the audit is a **no-op** on current code:
there is nothing to rewire, and nothing pointing at the wrong platform.

### Per-platform placements (Reddit / Quora / Medium and the rest)

Those tokens exist in the helper and are ready, but **no placement is published in the theme**, and I
deliberately did not invent links to social posts that do not exist yet. When a placement goes live
(a Reddit comment, a Quora answer, a Medium post), its CTA is one call away:

```php
insightistic_promo_url( 'rd' )   // Reddit
insightistic_promo_url( 'qr' )   // Quora
insightistic_promo_url( 'me' )   // Medium
insightistic_promo_url( 'custom' ) // the at3l106SYo short link
```

That is the honest position: the map is complete and tested, the placements are not fabricated.
