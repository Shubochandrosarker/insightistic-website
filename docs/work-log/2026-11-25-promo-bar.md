## Countdown mechanics (Shuvo's call)

- **Per-visitor evergreen window.** On first sight the browser stores `ins_promo_first_seen`; the
  target is `first_seen + 8d 23h 59m`, ticking every second (`Xd Xh Xm Xs`). Written once, never
  reset — a returning visitor's clock keeps running.
- **Expiry simplifies, never strands.** When the window ends, the countdown hides and the bar stays
  as badge + CTA.
- **Dismissible and remembered** (`ins_promo_dismissed`); a dismissed visitor never sees it again.
- **Optional hard end date:** `JOLLY_PROMO_END` (constant or theme mod) wins when set; otherwise the
  per-visitor window applies.

## Ship-day runbook — removing the AppSumo embed (host side)

ZCode decision (2): the embed is removed in WP admin content, not in this repo. Do it AFTER the
rebrand + top bar are live, so the site never has a gap or two promos at once.

**Where it hides.** The embed is a block of HTML containing `data-appsumo-embed="bar"` plus the
`embed.js` script tag. It is content, so check in this order:

1. **Widgets** — Appearance → Widgets → Footer areas (a Custom HTML widget is the usual home).
2. **Pages/posts/templates** — Pages → search each template used by the footer, or use the block
   editor's list view; also check any Elementor/theme-builder footer template (postmeta, not
   post_content).
3. **Theme options / Customizer** — any "footer HTML" or "custom code" field.
4. **Plugin settings** — a header/footer-scripts plugin, or AppSumo's own WP plugin if installed.

**Fastest way to find it** (read-only, run in phpMyAdmin or WP-CLI):

```sql
-- block content in posts/pages/reusable blocks
SELECT ID, post_type, post_title FROM wp_posts WHERE post_content LIKE '%data-appsumo-embed%';
-- widgets (Custom HTML lives in the widget_text option)
SELECT option_name FROM wp_options WHERE option_value LIKE '%data-appsumo-embed%';
-- page builders (Elementor/Divi store markup in postmeta)
SELECT post_id, meta_key FROM wp_postmeta WHERE meta_value LIKE '%data-appsumo-embed%';
```

**Remove:** delete the whole `<div data-appsumo-embed="bar">…</div>` block *and* the
`<script async src="https://appsumo.com/api/v2/embeds/v1/embed.js"></script>` tag that follows it.
If it lives in a page builder template, delete the HTML widget — do not just hide it with CSS,
because the script would still load and still call AppSumo.

**Verify:**

1. View the rendered page source: `data-appsumo-embed` and `embeds/v1/embed.js` must be gone.
2. Exactly one promo surface remains (the top bar), on desktop and mobile.
3. The bar's CTA still resolves to `https://appsumo.com/pl/insightistic-ai-business-intelligence-w/`.
4. No layout shift at the bottom of the page where the embed used to sit.

**On deal close (same day):** set `JOLLY_PROMO_END` to a past date (or remove
`template-parts/global/promo-bar.php` from `header.php`). The custom bar's countdown is evergreen by
design and will not stop on its own; AppSumo's embed would have.
